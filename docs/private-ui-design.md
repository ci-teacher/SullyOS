# Private UI visual direction

This private build treats SullyOS as a technical substrate. The visible product is the shared phone for Xiaoci + Laoshi.

## Core visual references

- Sanrio red-character sites: primary system reference. Strong flat color, patterns, character art, playful but controlled.
- Caramel Corn anniversary pages: high-priority reference for icon art, dots, gradients and decorative motifs.
- 31 Japan: reference for simple rounded Japanese logo language and small candy-gradient accents.
- niko and ... / Harajuku event sites: borrow collage and selected motion only; do not copy their page-level density.
- calm illustrated service sites: reference for app-internal pages that should feel mature + cute.
- themed quiz/game pages: only for mini-games and special-event screens.

## Rules

1. Keep normal app interaction patterns. This is a phone UI, not an advertising landing page.
2. Main palette: red + cream + dark ink. Pink is secondary. Small lilac / blue / mint / yellow accents are allowed.
3. Cute comes from icon art, patterns, badges, labels, typography and small illustrations — not from putting every feature inside a huge rounded card.
4. Use flat colors boldly. Polka dots, stripes and small gradients are first-class motifs.
5. Animation stays restrained in ordinary apps: press, pop, expand, switch. More expressive type/collage motion is reserved for games and special pages.
6. Hand-drawn private icons can replace every app icon without changing layout. Convention: public/media/private/icons/<app-id>.png.
7. Preserve useful app-like interaction patterns from SullyOS where they are already good; reskin rather than replacing functional UI for its own sake.
8. Avoid generic SaaS/dashboard language: no SYSTEM ONLINE, analytics cards, admin-console styling, glassmorphism everywhere, or “premium productivity” aesthetics.
9. Tag/chip language may use small numbered circles + thin borders, inspired by Japanese ranking/category labels.
10. Photo/diary pages may use collage and graph-paper motifs in moderation.
